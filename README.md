# Mod Control — Issue Tracker

This repository is used only for tracking bugs and feature requests for
**Mod Control**, a Minecraft Fabric mod. It does not contain the mod's
source code.

- 📦 Download the mod on [Modrinth](https://modrinth.com/mod/modcontrol)
- 🐞 Found a bug or have a suggestion? [Open an issue](https://github.com/Fortunich/modcontrol/issues)

When reporting a bug, please include:
- Minecraft version
- Fabric Loader / Combat Indicator version
- Steps to reproduce
- Screenshots or logs, if relevant
